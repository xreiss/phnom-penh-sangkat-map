# Phnom Penh — 14 Khan, 105 Sangkat

[Open the interactive map](https://xreiss.github.io/phnom-penh-sangkat-map/)

The map includes a search, Khan filter, Sangkat reference points, and links to check each point in Google Maps. The street-map background needs an internet connection.

The accompanying CSV lists Sangkat names, Khmer names, administrative codes, Khan, reference coordinates, and coordinate provenance.

## Data and limitations

Names and codes use Cambodia's 2025 geographical list published through the Ministry of Economy and Finance portal. Most reference coordinates come from the Ministry's Phnom Penh geographical coordinates dataset (2023); five missing coordinates use alternate sources noted in the CSV.

The points are for orientation only. They are not Sangkat boundaries, official centers, addresses, or cadastral locations. The map uses Esri World Street Map tiles and displays its attribution.
